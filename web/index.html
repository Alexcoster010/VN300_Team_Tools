    SOONER RACING TEAM

    From the car.
    To the next run.

    Capture trustworthy data. Compare drivers. Turn each session into a better setup.

    This console combines VN300 inertial and GPS data with steering, airspeed, SFM3505 mass flow, and optional passive CAN capture. All panel assets and analysis reports work offline.

    Trackside setup

    1. Connect hardware. Match VN300 and app baud rates (default 921600). Give the VN300 and Arduino separate stable serial paths. Arduino defaults to 115200 baud. Connect SFM3505 to Pi I²C and enable Pi I²C mass flow in Setup (bus 1 by default). For Uno A0/A1 voltages, select a0-a1-volts. Restart the service after changing device settings.
    2. Check storage and sensors. Logs prefer a USB drive and fall back to ~/vn300_logs. Use setup streaming to check readings without recording. Check mass flow and sensor status on Sensors.
    3. Prepare the run. Save driver and setup metadata on Track. On Setup, calibrate steering and define the start/finish gates. Lap uses one gate; autocross uses two.
    4. Record and review. Start/Stop Log or GPIO 17 toggles recording. Hold the power button on GPIO 27 about two seconds to flush and shut down. Download and analyze after capture finishes.

    Before vehicle use, verify sensor signs, GPS timing gates, serial rates, calibration, CAN decoding, USB fallback, and clean shutdown on the Pi.
